# 部署文档

## 一、云服务器（Linux：CentOS / Ubuntu）

### 1. 安装 MySQL 8 并建库

```bash
# Ubuntu
sudo apt update && sudo apt install -y mysql-server
# CentOS
sudo yum install -y mysql-server && sudo systemctl enable --now mysqld

# 建库建表
mysql -u root -p < server/schema.sql

# 创建专用账号（把密码换成你自己的）
mysql -u root -p -e "
CREATE USER 'notebook'@'127.0.0.1' IDENTIFIED BY '你的数据库密码';
GRANT ALL PRIVILEGES ON notebook.* TO 'notebook'@'127.0.0.1';
FLUSH PRIVILEGES;"
```

### 2. 编译服务端

在**本地开发机**交叉编译或在服务器上直接编译：

```bash
cd server
cargo build --release
# 产物：target/release/notebook-server（单文件，无需额外运行环境）
```

上传到服务器：

```bash
scp server/target/release/notebook-server root@你的服务器:/opt/notebook/
```

### 3. 配置并启动

```bash
mkdir -p /opt/notebook
cd /opt/notebook

# 生成一个随机 Token（客户端要填同样的值）
openssl rand -hex 24

cat > /opt/notebook/.env <<'EOF'
DATABASE_URL=mysql://notebook:你的数据库密码@127.0.0.1:3306/notebook
API_TOKEN=上一步生成的随机Token
BIND_ADDR=127.0.0.1:8787
RUST_LOG=info
EOF

chmod 600 /opt/notebook/.env
./notebook-server      # 先手工跑一次，确认能连上 MySQL
```

systemd 托管：

```ini
# /etc/systemd/system/notebook-server.service
[Unit]
Description=Notebook Sync Server
After=network.target mysql.service

[Service]
Type=simple
WorkingDirectory=/opt/notebook
ExecStart=/opt/notebook/notebook-server
Restart=always
RestartSec=3
# 内存上限（常驻远低于此值，仅作兜底）
MemoryMax=128M

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now notebook-server
sudo systemctl status notebook-server
curl -H "X-Api-Token: 你的Token" http://127.0.0.1:8787/api/ping
```

### 4. Nginx + HTTPS（强烈建议）

```nginx
server {
    listen 443 ssl http2;
    server_name note.example.com;

    ssl_certificate     /etc/letsencrypt/live/note.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/note.example.com/privkey.pem;

    client_max_body_size 20m;

    location /api/ {
        proxy_pass http://127.0.0.1:8787;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 60s;
    }
}

server {
    listen 80;
    server_name note.example.com;
    return 301 https://$host$request_uri;
}
```

安全组放行 **443**（若不用 Nginx 则放行 8787，但不建议明文暴露）。

### 5. 备份云端数据

```bash
# 每日 3 点备份，保留 14 天
0 3 * * * mysqldump -u notebook -p'密码' notebook | gzip > /backup/notebook-$(date +\%F).sql.gz
find /backup -name 'notebook-*.sql.gz' -mtime +14 -delete
```

## 二、客户端

### 1. 获取程序

**便携版（推荐）**：拿到 `WorkLog-便携版.zip`，解压到任意目录（本地磁盘、U 盘均可），
双击 `WorkLog\WorkLog.exe` 即可。程序与日志数据在同一个文件夹内，拷到别的电脑解压就能接着用。

**单文件 exe**：项目根目录的 `WorkLog.exe`，数据存在 `%APPDATA%\WorkLog\`。

两者是同一份程序，区别只在于 exe 旁边有没有 `portable.mode` 标记文件：

| 标记文件 | 数据位置 |
| --- | --- |
| 有 `portable.mode` | `<程序目录>\data\`（便携，随文件夹走） |
| 无 | `%APPDATA%\WorkLog\` |

需要重新打包时：

```bash
# 1) 打包 exe（或双击 desktop\build-exe.bat）
cd desktop && pyinstaller --noconfirm --onefile --windowed --name WorkLog ^
  --icon ../client/src-tauri/icons/icon.ico ^
  --add-data "%CD%\web;web" --add-data "%CD%\assets;assets" ^
  --distpath .. --workpath ../.build/work --specpath ../.build main.py

# 2) 生成便携压缩包（会把当前 %APPDATA%\WorkLog 的日志一并带入）
python scripts/make-portable.py
```

> 设计书原定的 Tauri 工程保留在 `client/src-tauri/`，需要 Rust 1.77+ 与 MSVC 生成工具，
> 装好后执行 `cd client && npm run tauri:build` 也能产出 exe。

### 2. 首次使用

1. 双击 `WorkLog.exe`，打开独立窗口；
2. 右上角齿轮 → 填写「云服务器地址」（如 `https://note.example.com`）与「API 访问 Token」；
3. 点「测试连接」，显示"连接成功"即配置正确；
4. 新建分支、写日志，全部即时保存在本地；
5. 联网时点「同步」上传/拉取。

### 3. 数据位置与迁移

| 模式 | 路径 |
| --- | --- |
| 便携版 | `<解压目录>\WorkLog\data\` |
| 单文件 exe | `%APPDATA%\WorkLog\` |

```
notebook.db      本地数据库（唯一主数据源）
config.json      云服务器配置
backups\         退出时自动备份，保留最近 5 份
```

迁移到新电脑：便携版整个文件夹拷走即可；`%APPDATA%` 模式则拷贝整个 `WorkLog` 目录。

### 4. 常见问题

**双击没反应 / 已有窗口**
程序已在运行，会把已有窗口切到前台；若看不到，请在任务栏查找。

**同步按钮是灰的**
- 处于离线状态；或
- 尚未配置服务器地址 / Token。

**同步报「Token 校验失败」**
客户端 Token 与服务端 `.env` 里的 `API_TOKEN` 不一致，改完保存后重试。

**同步报「无法连接云服务器」**
检查：安全组端口是否放行、Nginx 是否正常、`curl -H "X-Api-Token: xxx" https://域名/api/ping` 是否返回 JSON。

**程序启动失败**
查看 `%APPDATA%\WorkLog\error.log` 里的详细堆栈。


**出现冲突弹窗**
说明同一份数据在两台设备上都改过。逐条选择保留哪一版即可；「保留本地」会覆盖云端，「采用云端」会用云端内容覆盖本地。

**日期前缀不对**
目录日期取自本机系统时间，请先校准系统时间（软件不做时间校验）。
